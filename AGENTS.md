This is a React app build with TS

Styling: Tailwind
App level state: Zustand store in src/store.ts
Components lib: ShadCN
Icons: lucide-react
IndexedDB: dexie in src/db.ts

## Coding Style
Separate logics into separate functions when possible
Do NOT create large files with a lot of lines
Prefer to create separate components in individual files
Human readable code is important
